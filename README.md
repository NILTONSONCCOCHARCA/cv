# Portafolio web — Nilton Ever Soncco Charca

## Archivos
- `index.html`: contenido y estructura de la página.
- `style.css`: diseño, colores y adaptación a móviles.
- `script.js`: menú móvil y datos de contacto.
- `img/nilton-soncco.jpg`: fotografía de perfil.

## Personalizar
1. Abre `script.js` y completa `email` y `linkedin` si deseas publicar esos datos.
2. Para cambiar la foto, reemplaza `img/nilton-soncco.jpg` por otra imagen conservando el mismo nombre.
3. Edita los textos directamente en `index.html`.
4. Cambia colores, tamaños y tipografías en `style.css`.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube todos los archivos y la carpeta `img` manteniendo la estructura.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y `/ (root)`, y guarda.
5. GitHub mostrará la dirección pública de tu página.
